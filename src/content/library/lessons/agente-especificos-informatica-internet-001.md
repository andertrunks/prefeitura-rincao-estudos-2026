# Internet e navegadores — URL, abas, pesquisa, downloads, cookies e segurança

## 1. Referência ao edital

Esta subaula corresponde ao tópico **`aa-internet`**.

## 2. Internet x Web

**Internet** é a infraestrutura mundial de redes.

**Web** é um dos serviços usados sobre a Internet, acessado principalmente por navegadores.

Outros serviços incluem e-mail, transferência de arquivos e aplicações remotas.

## 3. Navegador x mecanismo de busca

Navegadores:
- Microsoft Edge;
- Google Chrome;
- Mozilla Firefox.

Mecanismos de busca:
- Google;
- Bing.

**Pegadinha:** Chrome é navegador; Google Search é mecanismo de busca.

## 4. URL

URL identifica endereço de um recurso.

Exemplo:
`https://www.rincao.sp.gov.br/noticia/concurso-publico-001-2026`

Pode conter:
- protocolo;
- domínio;
- caminho;
- parâmetros.

## 5. HTTP x HTTPS

HTTPS usa proteção criptográfica para a comunicação.

**Importante:** HTTPS reduz risco de interceptação, mas não garante que o site seja honesto. Um site fraudulento também pode ter certificado HTTPS.

## 6. Abas e janelas

Atalhos comuns:
- `Ctrl+T` — nova aba;
- `Ctrl+W` — fechar aba;
- `Ctrl+Shift+T` — reabrir aba fechada em navegadores comuns.

## 7. Favoritos e histórico

**Favoritos/marcadores:** guardam endereço para acesso posterior.

**Histórico:** registra páginas visitadas conforme configuração.

Limpar histórico não apaga necessariamente arquivos baixados.

## 8. Download x upload

**Download:** dados chegam ao dispositivo.

**Upload:** dados são enviados do dispositivo para serviço remoto.

Exemplo:
- baixar edital = download;
- anexar documento em formulário = upload.

## 9. Cache e cookies

**Cache:** guarda recursos temporários para acelerar carregamento.

**Cookies:** pequenos dados utilizados por sites para sessão, preferências e outras finalidades.

Cache ≠ cookie.

## 10. Navegação privada

Reduz armazenamento local de certos dados da sessão.

Não significa:
- anonimato absoluto;
- VPN;
- invisibilidade para provedor;
- imunidade a malware.

## 11. Pesquisa segura

Para concurso:
- prefira fonte oficial;
- confira domínio;
- confira data;
- diferencie anúncio de resultado;
- valide informação relevante.

## 12. Phishing

Phishing tenta induzir o usuário a fornecer:
- senha;
- token;
- dados pessoais;
- informações financeiras.

Sinais:
- urgência;
- ameaça;
- link estranho;
- domínio imitador;
- pedido de senha;
- anexo inesperado.

### QUESTÃO REAL — INEPAM

Em Clementina/SP, Concurso 001/2026, cargo **Agente Administrativo**, a INEPAM confirmou como correta a conduta de **não inserir credenciais e comunicar o setor de TI** diante de tentativa suspeita.

Esse é um exemplo de cobrança situacional de segurança.

## 13. bit x Byte

- `b` = bit;
- `B` = Byte;
- 1 Byte = 8 bits.

### QUESTÃO REAL — INEPAM

Em Sete Barras/SP, PSS 003/2026, Assistente Administrativo, a banca destacou a diferença entre **Gb** e **GB** e a relação 1 Byte = 8 bits.

Essa evidência é de Informática geral e reforça atenção a letras maiúsculas/minúsculas.

## 14. Sites e links

Antes de clicar:
- observe destino;
- confira domínio;
- evite executar arquivo inesperado;
- em ambiente institucional, siga política de segurança.

O texto visível de um link pode ser diferente do endereço real.

## 15. Pegadinhas

- Internet ≠ Web;
- navegador ≠ buscador;
- download ≠ upload;
- cache ≠ cookies;
- privado ≠ anônimo absoluto;
- HTTPS ≠ site confiável automaticamente;
- Gb ≠ GB.

## 16. Resumo

Domine navegador, URL, HTTP/HTTPS, abas, favoritos, histórico, downloads, cookies e segurança. Diante de phishing, não forneça credenciais.

## 17. Revisão rápida

1. Chrome/Edge/Firefox = navegadores.
2. Google/Bing = busca.
3. URL = endereço.
4. Ctrl+T = nova aba.
5. Download recebe; upload envia.
6. HTTPS protege transporte, não honestidade.
7. Phishing pede dados por engano.
8. 1 Byte = 8 bits.

## 18. Flashcards

**Chrome é quê?** Navegador.  
**Bing é quê?** Mecanismo de busca.  
**Ctrl+T?** Nova aba.  
**Download?** Receber dados.  
**Upload?** Enviar dados.  
**Cookie é igual a cache?** Não.  
**HTTPS garante site legítimo?** Não.  
**1 Byte?** 8 bits.  
**Gb e GB iguais?** Não.
