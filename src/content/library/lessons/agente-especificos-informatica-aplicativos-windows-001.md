# Aplicativos do Windows — Bloco de Notas, Calculadora, Paint e WordPad

## 1. Referência ao edital

Esta subaula corresponde ao tópico **`aa-aplicativos`** do projeto do site. O edital cita expressamente Bloco de Notas, Calculadora, Paint e WordPad.

O objetivo é reconhecer finalidade, diferenças e operações típicas de cada aplicativo.

## 2. Bloco de Notas

O Bloco de Notas é voltado a **texto simples**. É adequado para:
- anotações rápidas;
- arquivos `.txt`;
- conteúdo sem diagramação rica;
- copiar texto sem estilos complexos.

Não substitui o Word quando são necessários:
- estilos;
- tabelas complexas;
- cabeçalhos;
- mala direta;
- paginação avançada.

**Exemplo:** copiar um número de protocolo e uma observação curta para um `.txt`.

## 3. Texto simples x texto formatado

Texto simples guarda essencialmente caracteres. Um processador como Word trabalha com formatação, layout, estilos e objetos.

**Pegadinha:** extensão `.txt` não é a extensão padrão de um documento moderno do Word.

## 4. Calculadora

A Calculadora do Windows possui recursos que variam conforme versão, podendo incluir:
- padrão;
- científica;
- programador;
- cálculo de datas;
- conversões.

**Uso administrativo:** somas rápidas, porcentagens, diferença de datas e conversões.

Ela não substitui uma planilha quando é necessário manter dados, fórmulas e histórico de cálculo.

## 5. Paint

Paint é editor gráfico simples. Permite, conforme versão:
- desenhar;
- recortar;
- redimensionar;
- girar;
- inserir texto;
- trabalhar com cores;
- salvar imagens em formatos como PNG e JPEG.

**Exemplo:** recortar uma captura de tela para anexar a uma orientação interna.

## 6. WordPad

Historicamente, o WordPad ficou entre Bloco de Notas e Word:
- mais formatação que o Bloco de Notas;
- menos recursos que o Word;
- suporte histórico a RTF.

### Atualização importante

A Microsoft removeu o WordPad de todas as edições do **Windows 11 a partir da versão 24H2**.

Portanto:
- numa questão sobre Windows antigo, WordPad pode existir;
- numa questão expressamente sobre Windows 11 24H2 ou posterior, tratá-lo como aplicativo nativo presente é incorreto.

O edital ainda o cita porque admite Windows XP ou versão mais recente.

## 7. Comparação

| Aplicativo | Finalidade central |
|---|---|
| Bloco de Notas | texto simples |
| Calculadora | cálculos e conversões |
| Paint | edição gráfica simples |
| WordPad | editor de texto básico/legado |

**Inferência editorial:** pela forma de cobrança observada em Informática, é razoável esperar comparação de finalidades, formatos e recursos disponíveis em determinada versão.

## 9. Pegadinhas

- Bloco de Notas não é Word.
- Paint não é editor de planilhas.
- Calculadora não guarda uma planilha de dados.
- WordPad não está presente no Windows 11 24H2+.
- `.txt` não preserva formatação avançada de Word.

## 10. Resumo

Bloco de Notas = texto simples; Calculadora = cálculo; Paint = imagem; WordPad = editor básico legado e removido nas versões atuais do Windows 11.
