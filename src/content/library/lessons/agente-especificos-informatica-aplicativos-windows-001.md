### Regra de versão

“Windows XP ou mais recente” não autoriza tratar todas as versões como iguais. Para esta aula:

- estudamos a **finalidade central** de cada aplicativo;
- indicamos recursos documentados nas versões atuais quando isso ajuda a prova;
- recursos recentes não são projetados retroativamente para o Windows XP;
- recursos históricos não são apresentados como se continuassem instalados em toda versão atual;
- quando uma questão informar uma versão específica, a resposta deve respeitar aquela versão.

### Caso especial: WordPad

O edital de Rincão cita WordPad e, portanto, ele **continua obrigatório no material de estudo**.

Ao mesmo tempo, a Microsoft informa oficialmente que o WordPad foi **removido de todas as edições do Windows a partir do Windows 11 versão 24H2** e do Windows Server 2025.

Consequência editorial:

- em questão sobre versões antigas, WordPad pode ser tratado como aplicativo histórico do Windows;
- em questão sobre Windows 11 24H2 ou posterior, não se deve presumir que WordPad esteja disponível como aplicativo nativo;
- a Microsoft recomenda **Word** para documentos de texto formatado, como `.doc` e `.rtf`, e **Bloco de Notas** para texto simples, como `.txt`.

## 4. Explicação completa e didática

### 4.1 Visão geral: escolha o aplicativo pela tarefa

Uma maneira segura de estudar é associar **tarefa → aplicativo**:

| Tarefa principal | Aplicativo mais associado |
|---|---|
| Escrever texto simples | Bloco de Notas |
| Fazer cálculos | Calculadora |
| Criar/editar imagem | Paint |
| Editar texto com formatação mais rica em versões antigas compatíveis | WordPad |

Essa tabela não significa que versões modernas não acrescentem funções. Significa apenas que a **finalidade central** é o primeiro critério para eliminar alternativas erradas.

### 4.2 Bloco de Notas: texto simples

O **Bloco de Notas** é um editor de texto simples.

Uso típico:

- anotações rápidas;
- arquivos `.txt`;
- pequenos registros;
- leitura/edição de conteúdo textual sem estrutura complexa de documento.

Em comparação com um processador de texto completo, o foco é a simplicidade.

#### Texto simples não é o mesmo que documento formatado

Texto simples guarda principalmente os caracteres do conteúdo. Um documento com formatação rica pode guardar informações como:

- tipo e tamanho de fonte;
- negrito;
- itálico;
- parágrafos;
- outros atributos de apresentação.

Para a prova, pense assim:

- `.txt` → texto simples → Bloco de Notas;
- `.rtf` → texto formatado → historicamente WordPad; nas versões atuais sem WordPad, Microsoft recomenda Word.

#### Recurso `.LOG`

A ajuda oficial atual da Microsoft documenta um recurso clássico:

1. abrir o Bloco de Notas;
2. digitar `.LOG` na primeira linha;
3. salvar o arquivo;
4. reabrir posteriormente.

Ao reabrir, a data e a hora atuais são acrescentadas ao final do registro, antes do ponto onde será digitado o próximo texto.

Situação prática:

Um setor quer manter um registro cronológico simples de ocorrências internas. O arquivo com `.LOG` pode ajudar a inserir automaticamente data e hora a cada reabertura.

#### Cabeçalho e rodapé na impressão

A Microsoft documenta comandos de configuração de página no Bloco de Notas.

Alguns códigos úteis:

| Código | Função |
|---|---|
| `&l` | alinhar à esquerda o conteúdo seguinte |
| `&c` | centralizar o conteúdo seguinte |
| `&r` | alinhar à direita o conteúdo seguinte |
| `&d` | imprimir a data atual |
| `&t` | imprimir a hora atual |
| `&f` | imprimir o nome do documento |
| `&p` | imprimir o número da página |

A configuração padrão documentada usa:

- cabeçalho: `&f`;
- rodapé: `Página &p`.

Ponto de prova: a própria Microsoft informa que essas configurações **não podem ser salvas**; é necessário inseri-las novamente quando se deseja imprimir com determinada configuração.

### 4.3 Calculadora: do básico aos modos avançados

A **Calculadora** é o aplicativo voltado a operações matemáticas.

Nas versões atuais documentadas pela Microsoft, o menu permite alternar entre modos como:

- **Padrão** — aritmética básica;
- **Científico** — cálculos avançados;
- **Gráficos** — plotagem de equações;
- **Programador** — binário, hexadecimal e outros recursos relacionados;
- **Cálculo de data** — diferença entre datas.

#### Conversores

A Calculadora atual inclui conversores, por exemplo:

- moeda;
- volume;
- comprimento;
- temperatura.

No conversor de moedas, as taxas são atualizadas automaticamente quando há conexão com a Internet.

#### Histórico e memória

A documentação atual também destaca:

- **Histórico** para revisar cálculos anteriores;
- memória com botões como `MC`, `MR`, `M+` e `M−`;
- possibilidade de manter a Calculadora visível acima de outros aplicativos no modo Padrão.

Atenção: versões antigas do Windows podem ter menos modos ou organização diferente. Se o enunciado indicar Windows XP, não suponha que toda função descrita na documentação atual já existia com o mesmo nome.

### 4.4 Paint: criação e edição de imagens

O **Paint** é associado à criação, desenho e edição de imagens.

A página oficial atual da Microsoft lista operações como:

- recortar;
- inverter;
- girar;
- redimensionar;
- usar pincéis;
- preencher áreas;
- selecionar cores;
- inserir texto;
- ampliar a visualização.

A Microsoft também possui recursos modernos adicionais no Paint de versões recentes. Esses recursos **dependem da versão e do ambiente** e não devem ser tratados como se existissem em todo Windows desde o XP.

#### Paint não é processador de texto

A ferramenta de texto do Paint permite inserir texto **dentro da imagem**. Isso não transforma o Paint em Word, WordPad ou Bloco de Notas.

#### Operações comuns

**Recortar (crop)**
- mantém uma área desejada e remove áreas externas conforme a seleção/recorte.

**Redimensionar**
- altera dimensões da imagem.

**Girar**
- muda a orientação.

**Inverter**
- espelha a imagem conforme o comando disponível.

**Copiar e colar**
- permite reutilizar conteúdo de imagem.

### 4.5 WordPad: conteúdo histórico que continua no edital

O **WordPad** foi, durante muitos anos, um editor de texto intermediário entre:

- Bloco de Notas, mais simples;
- Word, muito mais completo.

Ele permitia editar documentos com formatação maior que a oferecida pelo Bloco de Notas, e ficou associado ao uso de documentos como `.rtf`.

#### O que mudou nas versões atuais

A Microsoft registra que:

> WordPad foi removido de todas as edições do Windows a partir do Windows 11 versão 24H2 e do Windows Server 2025.

Também informa que, com a remoção, o Windows deixa de possuir um leitor RTF interno e padrão, recomendando:

- **Microsoft Word** para `.doc` e `.rtf`;
- **Bloco de Notas** para `.txt`.

#### Como responder em prova

**Se o enunciado falar em Windows XP, 7, 8, 10 ou outro ambiente antigo em que WordPad esteja disponível:**

trate WordPad como editor histórico de texto com formatação.

**Se o enunciado falar em Windows 11 24H2 ou versão posterior:**

não marque uma alternativa que dependa da presença nativa do WordPad sem uma ressalva específica do enunciado.

**Se o enunciado apenas reproduzir o edital e perguntar a finalidade histórica do WordPad:**

responda pela finalidade tradicional, pois o edital ainda o exige.

### 4.6 “Aplicativo embarcado” não significa “imutável para sempre”

O edital usa uma lista tradicional de aplicativos do Windows. Software evolui.

Um aplicativo pode:

- ganhar recursos;
- mudar interface;
- ser separado ou distribuído de outra forma;
- ser descontinuado;
- ser removido.

Por isso, memorizar somente uma tela antiga é uma estratégia fraca. A base deve ser:

**finalidade + recurso principal + versão quando indicada.**

## 5. Conceitos e regras fundamentais

### Regra 1 — finalidade central primeiro

- Bloco de Notas → texto simples;
- Calculadora → cálculos;
- Paint → imagens;
- WordPad → texto com maior formatação em contexto histórico compatível.

### Regra 2 — não confundir arquivo com aplicativo

`.txt`, `.rtf`, `.png` e outros são formatos/extensões. Bloco de Notas, WordPad e Paint são aplicativos.

### Regra 3 — recurso atual não é regra retroativa

Se uma função apareceu em versão recente, não conclua que existia no XP.

### Regra 4 — recurso histórico não é presença universal atual

WordPad é exigido pelo edital, mas foi removido de todas as edições do Windows a partir do Windows 11 24H2.

### Regra 5 — versão indicada vincula a análise

Uma questão pode fixar explicitamente Windows 11 25H2, por exemplo. Nesse caso, não responda com base apenas na memória de Windows 7 ou 10.

### Regra 6 — Microsoft é fonte técnica prioritária para estado atual

Para disponibilidade e recursos atuais, a documentação oficial do fabricante prevalece sobre tutoriais genéricos.

### Regra 7 — evidência de banca não vira regra universal de software

Quando um julgamento da INEPAM fundamenta uma resposta em um ambiente específico, isso mostra **como aquela questão foi decidida**. Não significa que todo detalhe técnico deva ser generalizado para qualquer versão, configuração ou contexto.

## 6. Exemplos resolvidos ou situações práticas

### Exemplo 1 — anotação simples

**Situação:** o setor precisa salvar rapidamente uma lista de telefones em texto puro.

**Raciocínio:**

1. não há necessidade de layout elaborado;
2. o conteúdo é textual;
3. o formato simples é adequado.

**Aplicativo:** Bloco de Notas.

### Exemplo 2 — registro cronológico

**Situação:** deseja-se que um arquivo simples acrescente data e hora a cada reabertura.

**Solução:** usar `.LOG` na primeira linha do arquivo do Bloco de Notas, conforme documentação oficial da Microsoft.

### Exemplo 3 — trigonometria

**Situação:** é necessário calcular seno, cosseno ou logaritmo em versão atual da Calculadora.

**Solução:** modo Científico.

### Exemplo 4 — binário e hexadecimal

**Situação:** é preciso converter/trabalhar com representações usadas em programação.

**Solução:** modo Programador da Calculadora atual.

### Exemplo 5 — diferença de datas

**Situação:** deseja-se saber o intervalo entre duas datas.

**Solução:** modo Cálculo de data da Calculadora atual.

### Exemplo 6 — imagem para comunicado

**Situação:** uma captura de tela precisa ser recortada e redimensionada antes de ser anexada a um comunicado interno.

**Solução:** Paint é adequado para edição básica de imagem.

### Exemplo 7 — arquivo RTF em computador antigo

**Situação:** em um computador com versão antiga do Windows que ainda possui WordPad, é preciso ajustar formatação de um `.rtf`.

**Solução histórica:** WordPad.

### Exemplo 8 — arquivo RTF em Windows 11 24H2+

**Situação:** o computador usa Windows 11 24H2 ou posterior.

**Raciocínio:**

1. WordPad foi removido nessa linha de versão;
2. não se deve assumir sua presença nativa;
3. a Microsoft recomenda Word para `.rtf`.

**Solução atual indicada pela Microsoft:** Microsoft Word.

## 8. Pegadinhas e erros frequentes

1. **“WordPad está em todo Windows atual.”** — errado; foi removido a partir do Windows 11 24H2.
2. **“Como WordPad foi removido, posso ignorá-lo.”** — errado; o edital de Rincão ainda o cita.
3. **“Paint serve principalmente para editar texto.”** — errado; sua finalidade central é imagem.
4. **“A ferramenta Texto transforma o Paint em processador de texto.”** — errado.
5. **“Bloco de Notas é o melhor para formatação rica.”** — errado; seu foco é texto simples.
6. **“Modo Programador da Calculadora é para desenhar imagens.”** — errado; trabalha com representações como binário/hexadecimal.
7. **“Modo Cálculo de data é igual ao modo Científico.”** — errado; possuem finalidades distintas.
8. **“&p imprime o nome do arquivo.”** — errado; `&p` é número da página; `&f` é nome do documento.
9. **“As configurações de cabeçalho/rodapé do Bloco de Notas ficam salvas.”** — a documentação oficial atual informa que não.
10. **“Todo recurso atual do Paint existia no XP.”** — não se pode presumir isso.
11. **“Se uma questão real de recurso disser algo sobre um aplicativo, posso recriar as alternativas que faltam.”** — proibido editorialmente.
12. **“Aplicativo embarcado” significa que ele jamais será removido.”** — a história do WordPad prova o contrário.

## 13. Gabarito comentado

**1. C** — O Bloco de Notas é o editor indicado para texto sem formatação. A própria Microsoft o recomenda para documentos de texto simples, como arquivos .txt.

**2. B** — O núcleo da distinção é texto simples no Bloco de Notas versus edição com maior riqueza de formatação no WordPad histórico. WordPad não está presente como aplicativo nativo em todas as versões atuais.

**3. E** — A Microsoft documenta o uso de .LOG na primeira linha para fazer o Bloco de Notas acrescentar data e hora quando o arquivo for reaberto.

**4. D** — Na configuração de impressão do Bloco de Notas, &p imprime o número da página. Já &f representa o nome do documento.

**5. D** — A documentação oficial informa que as configurações de cabeçalho e rodapé não podem ser salvas e devem ser inseridas manualmente em cada impressão desejada.

**6. B** — O modo Científico é destinado a cálculos avançados. O modo Padrão atende à aritmética básica.

**7. C** — A Microsoft descreve o modo Programador como apropriado para binário, hexadecimal e operações relacionadas.

**8. A** — O modo Cálculo de data permite calcular diferenças entre datas. Recursos disponíveis podem variar em versões antigas do Windows.

**9. C** — A documentação atual informa que o conversor de moedas atualiza as taxas automaticamente quando há conexão com a Internet.

**10. B** — A Microsoft descreve o modo Gráficos como apropriado para plotar equações. As demais associações misturam finalidades de outros aplicativos.

**11. E** — O Paint é o aplicativo de criação e edição de imagens. Essa finalidade também aparece explicitamente em julgamento oficial da INEPAM.

**12. A** — A Microsoft lista recorte, inversão, rotação e redimensionamento como operações de manipulação de imagens no Paint atual.

**13. A** — Pincéis, preenchimento, seletor de cores e texto pertencem ao universo de edição do Paint. As demais alternativas descrevem outros aplicativos.

**14. C** — O edital abrange várias gerações do Windows. A finalidade básica do Paint é transversal, mas recursos atuais, inclusive alguns recentes, não devem ser projetados retroativamente para versões antigas.

**15. B** — O WordPad tradicionalmente funcionava como editor de textos com recursos de formatação superiores aos do Bloco de Notas, sendo associado a formatos como RTF.

**16. E** — A Microsoft registra a remoção do WordPad de todas as edições do Windows a partir do Windows 11 versão 24H2, além do Windows Server 2025.

**17. A** — A Microsoft recomenda Word para documentos de texto formatado, como .doc e .rtf, e Bloco de Notas para texto simples, como .txt.

**18. A** — A sequência associa cada tarefa à finalidade central do aplicativo: texto simples → Bloco de Notas; cálculo avançado → Calculadora; imagem → Paint; texto formatado em ambiente histórico compatível → WordPad.
