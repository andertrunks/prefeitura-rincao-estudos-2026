## 4. Explicação completa e didática

### 4.1 O que é sistema operacional

O sistema operacional é o software fundamental que administra recursos do computador e oferece a interface usada por pessoas e programas.

O Windows gerencia, entre outras coisas:

- arquivos;
- pastas;
- memória;
- programas;
- dispositivos;
- contas de usuário;
- processos;
- armazenamento;
- tela;
- energia;
- atualizações.

Exemplo:

Ao editar uma planilha:

- o Excel trabalha com o conteúdo da planilha;
- o Windows gerencia a janela, o arquivo, a pasta, a unidade de armazenamento e o acesso aos dispositivos.

### 4.2 Versão XP ou mais recente

O edital utiliza uma fórmula frequente da INEPAM:

> Windows versão XP ou mais recente.

Isso não significa que você precise decorar cada menu de todas as versões.

A estratégia correta é:

**Camada 1 — conceitos estáveis**
- arquivo;
- pasta;
- atalho;
- Lixeira;
- copiar;
- mover;
- janelas;
- unidades;
- propriedades.

**Camada 2 — recursos comuns modernos**
- Explorador de Arquivos;
- Configurações;
- pesquisa;
- escala;
- atualização.

**Camada 3 — caminho específico de versão**
- estudar somente quando a questão informar a versão.

A própria INEPAM registrou em julgamento oficial que a versão informada no enunciado deve ser considerada.

### 4.3 Windows XP e Windows atuais

Em versões antigas, como XP, você encontrará termos e interfaces como:

- **Meu Computador**;
- **Windows Explorer**;
- **Painel de Controle**;
- Menu Iniciar clássico.

Em versões recentes:

- **Este Computador**;
- **Explorador de Arquivos**;
- aplicativo **Configurações**;
- Painel de Controle ainda existe para várias funções;
- Menu Iniciar e barra de tarefas possuem desenho diferente.

Pegadinha:

> uma função pode continuar existindo mesmo que seu caminho visual mude.

### 4.4 Área de Trabalho

A Área de Trabalho é o espaço visual principal após o login.

Pode conter:

- ícones;
- atalhos;
- arquivos;
- pastas;
- Lixeira.

Cuidado:

um ícone na Área de Trabalho pode representar:

- arquivo real;
- pasta real;
- atalho.

Não conclua que todo ícone é atalho.

### 4.5 Menu Iniciar

O Menu Iniciar permite acessar recursos como:

- aplicativos;
- pesquisa;
- configurações;
- opções de energia;
- conta do usuário.

Seu desenho mudou bastante ao longo das versões.

Para a prova, priorize a função, não a aparência exata, salvo quando a versão estiver indicada.

### 4.6 Barra de tarefas

A barra de tarefas permite:

- ver aplicativos abertos;
- iniciar aplicativos fixados;
- alternar entre janelas;
- acessar área de notificação;
- verificar relógio e outros indicadores.

Em versões modernas, a posição visual padrão pode variar.

### 4.7 Janela

Elementos frequentes de uma janela:

- barra de título;
- botão minimizar;
- botão maximizar;
- botão restaurar;
- botão fechar;
- área de conteúdo;
- barras de rolagem;
- menus ou comandos.

### 4.8 Minimizar

Minimizar:

- esconde a janela da área principal;
- normalmente mantém o aplicativo em execução;
- permite recuperá-la pela barra de tarefas.

**Minimizar não é fechar.**

### 4.9 Maximizar e restaurar

Maximizar:

- amplia a janela para ocupar a área disponível.

Restaurar:

- devolve a janela ao tamanho/posição anterior.

### 4.10 Fechar

Fechar encerra a janela.

Dependendo do programa:

- pode encerrar o aplicativo;
- pode apenas fechar o documento/janela;
- pode solicitar salvamento de alterações.

### 4.11 Arquivo

Arquivo é uma unidade de informação armazenada.

Exemplos:

- `relatorio.docx`;
- `planilha.xlsx`;
- `foto.jpg`;
- `edital.pdf`.

O nome e a extensão ajudam a identificar seu conteúdo/formato.

### 4.12 Pasta

Pasta é um contêiner lógico usado para organizar:

- arquivos;
- outras pastas.

Exemplo:

`Documentos\Prefeitura\RH`

Nesse exemplo:

- Documentos é pasta;
- Prefeitura é subpasta;
- RH é subpasta de Prefeitura.

### 4.13 Unidade

Uma unidade representa determinado armazenamento ou volume.

Exemplos:

- `C:`;
- `D:`;
- unidade USB;
- unidade de rede.

Em caminho tradicional do Windows, a letra costuma ser seguida de dois-pontos.

### 4.14 Caminho

Exemplo:

`C:\Prefeitura\RH\Frequencia\agosto.xlsx`

Interpretação:

- `C:` — unidade;
- `Prefeitura` — pasta;
- `RH` — subpasta;
- `Frequencia` — subpasta;
- `agosto.xlsx` — arquivo;
- `.xlsx` — extensão.

A prova pode apresentar um caminho e perguntar qual é:

- unidade;
- pasta;
- nome do arquivo;
- extensão.

### 4.15 Extensão

Extensão é a parte final do nome associada ao formato.

Exemplos:

- `.txt`;
- `.docx`;
- `.xlsx`;
- `.pptx`;
- `.pdf`;
- `.jpg`;
- `.png`;
- `.zip`.

### 4.16 Extensão oculta

O Windows pode ser configurado para ocultar extensões conhecidas.

Isso pode confundir o usuário.

Exemplo visual:

`relatorio.pdf`

pode, em situação maliciosa, ser algo diferente se a extensão real estiver oculta.

Para prova, saiba:

> exibir ou ocultar extensões é uma configuração do Explorador.

### 4.17 Explorador de Arquivos

O Explorador de Arquivos é usado para gerenciar arquivos, pastas e unidades.

Permite:

- navegar;
- criar pastas;
- copiar;
- mover;
- excluir;
- renomear;
- pesquisar;
- ordenar;
- visualizar propriedades;
- acessar unidades externas.

No Windows XP, a denominação tradicional é **Windows Explorer**.

### 4.18 Criar pasta

Uma pasta pode ser criada em determinado local para organizar documentos.

Exemplo administrativo:

`C:\Prefeitura\Compras\2026`

Boa prática:

- nomes descritivos;
- evitar arquivos espalhados;
- manter padrão de organização.

### 4.19 Seleção de itens

Uma questão pode explorar:

- selecionar um item;
- selecionar vários;
- selecionar tudo.

Atalho frequente:

`Ctrl+A` — selecionar tudo no contexto ativo.

### 4.20 Copiar

Copiar:

- mantém o item original;
- cria cópia no destino.

Fluxo clássico:

1. selecionar;
2. `Ctrl+C`;
3. abrir destino;
4. `Ctrl+V`.

### 4.21 Recortar e mover

Recortar normalmente prepara o item para ser movido.

Fluxo:

1. `Ctrl+X`;
2. destino;
3. `Ctrl+V`.

Diferença essencial:

**copiar**
- original permanece.

**mover**
- item muda de localização.

### 4.22 Arrastar com o mouse

Arrastar arquivos pode produzir resultados diferentes conforme origem e destino.

Em prova básica, não presuma regra absoluta sem contexto.

Se a questão não especificar unidades ou teclas modificadoras, prefira conceitos mais seguros de copiar/mover via comandos.

### 4.23 Renomear

Renomear altera o nome do item, não seu conteúdo por si só.

Atalho comum no Explorador:

`F2`.

Pegadinha:

renomear a extensão pode afetar a associação/formato percebido, mas não converte magicamente o conteúdo.

Trocar:

`arquivo.txt`

por:

`arquivo.pdf`

não transforma um arquivo de texto em PDF real.

### 4.24 Excluir

A tecla `Delete`, em contexto comum do Explorador e unidade local, envia o item à Lixeira.

Mas existem exceções.

Por isso, a formulação segura é:

> a exclusão comum de muitos itens locais pode encaminhá-los à Lixeira.

### 4.25 Shift+Delete

`Shift+Delete` normalmente solicita exclusão sem enviar o item à Lixeira.

Essa é uma pegadinha clássica.

### 4.26 Lixeira

A Lixeira permite:

- visualizar itens excluídos;
- restaurar;
- esvaziar.

Restaurar normalmente devolve o item à localização original.

### 4.27 Nem toda exclusão passa pela Lixeira

Pode haver exclusão permanente em situações como:

- `Shift+Delete`;
- algumas unidades removíveis;
- compartilhamentos/rede;
- arquivos grandes conforme configuração;
- comandos específicos.

Logo:

> “todo arquivo excluído sempre vai para a Lixeira” é falso.

### 4.28 Atalho

Atalho é uma referência para outro item.

Pode apontar para:

- programa;
- arquivo;
- pasta;
- local.

Excluir apenas o atalho:

- normalmente remove a referência;
- não apaga o item original.

### 4.29 Atalho não é cópia

Se você criar um atalho para `relatorio.docx`, não criou uma segunda cópia do documento.

Você criou um meio de acesso.

### 4.30 Propriedades

As propriedades de um item podem apresentar informações como:

- tipo;
- localização;
- tamanho;
- datas;
- atributos.

Atalho de teclado documentado pela Microsoft:

`Alt+Enter` — propriedades do item selecionado em diversos contextos do Windows/Explorador.

### 4.31 Pesquisa

O Windows permite pesquisar:

- aplicativos;
- arquivos;
- configurações.

No Explorador, a pesquisa pode ser feita dentro da pasta/unidade atual.

Atalhos do Explorador documentados pela Microsoft incluem:

- `Ctrl+E`;
- `Ctrl+F`;

para focar a pesquisa em contextos atuais.

### 4.32 Ordenação

Arquivos podem ser ordenados por critérios como:

- nome;
- data;
- tipo;
- tamanho.

Ordenar não altera necessariamente o conteúdo do arquivo.

### 4.33 Compactação ZIP

O Windows trabalha com arquivos compactados `.zip`.

Em noção básica:

**compactar**
- agrupa arquivos e pode reduzir tamanho.

**extrair**
- retira o conteúdo do pacote.

Não confunda compactar com excluir.

### 4.34 Sistemas de arquivos

Sistemas de arquivos organizam dados em uma unidade.

No ecossistema Windows, exemplos comuns:

- NTFS;
- FAT;
- FAT32;
- exFAT.

### 4.35 Evidência real INEPAM — EXT4

No Concurso Público nº 001/2024 de Itajubá/MG:

- banca: INEPAM;
- cargo: **Agente Administrativo**;
- Questão 19.

O julgamento oficial afirma que, no contexto de Windows 11 usado na questão, eram aceitos:

- FAT;
- FAT32;
- exFAT;
- NTFS;

e a alternativa **EXT4** era a incompatível, associada ao Linux.

### Importante

Use essa afirmação como:

> **padrão comprovado da questão da banca naquele contexto.**

Não extrapole para discussões avançadas sobre WSL, montagem de discos Linux ou ferramentas especiais que não eram o objeto da prova.

### 4.36 Configurações

Nas versões modernas, o aplicativo **Configurações** centraliza grande parte das opções.

Categorias podem envolver:

- Sistema;
- Bluetooth e dispositivos;
- Rede e Internet;
- Personalização;
- Aplicativos;
- Contas;
- Hora e idioma;
- Acessibilidade;
- Privacidade e segurança;
- Windows Update.

A nomenclatura varia com a versão.

### 4.37 Painel de Controle

O Painel de Controle é tradicional no Windows.

Em versões modernas:

- continua existindo;
- parte das configurações migrou para o aplicativo Configurações.

No Windows XP, ele possui papel muito mais central.

### 4.38 Escala x resolução

**Escala**
- altera o tamanho visual de texto, aplicativos e elementos.

**Resolução**
- relaciona-se à quantidade de pixels usada pela tela.

Não são sinônimos.

### 4.39 Evidência real INEPAM — Escala

Itajubá/MG, Concurso nº 001/2024, Agente Administrativo, Questão 20.

A banca registrou:

> Configurações → Sistema → Tela → Escala.

O enunciado utilizava:

> Windows 11 23H2.

O julgamento ressaltou expressamente que a versão indicada na questão deveria ser considerada.

### 4.40 Fonte Microsoft atual sobre escala

O suporte atual da Microsoft também apresenta, para Windows 11:

- Configurações;
- Sistema;
- Tela;
- seção Escala e layout;
- opção Escala.

Essa fonte confirma que a ideia central continua válida, embora nomes/localização possam mudar futuramente.

### 4.41 Resolução recomendada

A Microsoft orienta, em geral, utilizar a resolução marcada como recomendada para o monitor.

Resoluções inadequadas podem deixar:

- texto menos nítido;
- imagem esticada;
- imagem pequena;
- bordas.

### 4.42 Atalhos de teclado de alta prioridade

| Atalho | Função principal |
|---|---|
| `Win+E` | abrir Explorador de Arquivos |
| `Win+D` | mostrar/ocultar Área de Trabalho |
| `Win+L` | bloquear o computador |
| `Alt+Tab` | alternar entre janelas/aplicativos |
| `Alt+F4` | fechar janela/aplicativo ativo |
| `Ctrl+C` | copiar |
| `Ctrl+X` | recortar |
| `Ctrl+V` | colar |
| `Ctrl+Z` | desfazer |
| `Ctrl+A` | selecionar tudo |
| `F2` | renomear item selecionado |
| `Alt+Enter` | propriedades do item |
| `Ctrl+Shift+Esc` | abrir Gerenciador de Tarefas |
| `Shift+Delete` | excluir sem enviar normalmente à Lixeira |

A Microsoft mantém uma lista oficial atualizada de atalhos.

### 4.43 Área de transferência

A área de transferência guarda temporariamente conteúdo copiado/recortado.

`Ctrl+C` e `Ctrl+X` colocam informação disponível para `Ctrl+V`.

Em Windows modernos, `Win+V` pode abrir o histórico da Área de Transferência quando o recurso está habilitado.

**Isso não é recurso do Windows XP.**

### 4.44 Bloquear

Bloquear:

- mantém a sessão aberta;
- exige autenticação para voltar;
- não equivale a desligar.

Atalho:

`Win+L`.

Em ambiente administrativo, bloquear o computador ao se afastar é boa prática.

### 4.45 Sair da conta

Sair:

- encerra a sessão do usuário;
- fecha programas da sessão conforme processo de saída;
- mantém o computador ligado.

### 4.46 Suspender

Suspender:

- reduz consumo;
- mantém estado para retorno rápido;
- não equivale a desligamento completo.

### 4.47 Hibernar

Quando disponível:

- salva o estado da sessão em armazenamento;
- reduz consumo de modo mais profundo que suspensão;
- pode não aparecer em toda configuração.

### 4.48 Reiniciar

Reiniciar:

- encerra a sessão/sistema;
- inicia novamente.

Pode ser necessário após:

- atualizações;
- instalação;
- correção de determinados problemas.

### 4.49 Desligar

Desligar encerra o funcionamento normal do sistema.

Não é igual a:

- bloquear;
- sair;
- suspender.

### 4.50 Evidência recente INEPAM — energia no Windows 11 25H2

Em julgamento oficial do Concurso nº 001/2025 de Nova Monte Verde/MT, publicado em dezembro de 2025, a INEPAM analisou questão sobre **Windows 11 25H2**.

O documento registra que o tempo de suspensão é configurado em:

> Configurações → Sistema → Energia e bateria

e nas opções de:

> tempo limite de tela, suspensão e hibernação.

Isso reforça dois pontos editoriais:

1. a banca cobra caminhos de menus;
2. a banca utiliza versões recentes do Windows.

### 4.51 Windows Update

Windows Update gerencia atualizações do sistema.

Em prova básica:

- atualizações corrigem falhas;
- podem acrescentar recursos;
- podem exigir reinicialização;
- atualizações de segurança são importantes.

Não confunda:

**Windows Update**
- atualização do sistema.

**Microsoft Store**
- distribuição/atualização de aplicativos, em vários cenários.

### 4.52 Fim do suporte do Windows 10

A Microsoft informa que o suporte do Windows 10 terminou em:

> **14/10/2025.**

Isso significa que, no suporte padrão:

- não recebe atualizações gratuitas regulares de software;
- não recebe correções normais de segurança;
- não recebe assistência técnica padrão.

O computador não “para de funcionar” automaticamente.

### 4.53 O Windows 10 ainda pode cair?

Sim.

O edital diz:

> XP ou mais recente.

Assim, uma versão fora de suporte continua dentro da literalidade do edital.

Porém, a INEPAM demonstra preferência recente por versões modernas quando especifica a versão da prova.

### 4.54 Windows 11 em 2026

A página oficial de saúde de versões da Microsoft, consultada em 30/08/2026, lista versões atuais do Windows 11, incluindo:

- 26H1;
- 25H2;
- 24H2;

além de canais/edições com ciclos diferentes.

Não memorize números de build salvo se a questão trouxer isso.

O importante é:

> o Windows continua evoluindo e o caminho visual de uma configuração pode mudar.

### 4.55 Gerenciador de Tarefas

O Gerenciador de Tarefas permite visualizar informações sobre:

- aplicativos;
- processos;
- desempenho;
- inicialização, conforme a versão;
- usuários, conforme a versão.

Atalho moderno comum:

`Ctrl+Shift+Esc`.

Não é necessário aprofundar administração de processos para este cargo.

### 4.56 Nome de arquivos

Em rotina administrativa, use nomes claros.

Exemplo melhor:

`Relatorio_Frequencia_2026-08.xlsx`

em vez de:

`novo1.xlsx`

A prova pode cobrar operações, não boas práticas de nomenclatura, mas exemplos claros ajudam a interpretar pastas e caminhos.

### 4.57 Salvar x mover arquivo

Salvar:

- grava conteúdo no arquivo.

Mover:

- altera a localização.

Salvar Como:

- pode criar outro arquivo/nome/local conforme o aplicativo.

Esses conceitos não são idênticos.

### 4.58 Abrir x executar

Abrir um documento:

- utiliza aplicativo associado.

Executar um programa:

- inicia software executável.

Uma extensão ajuda o Windows a decidir qual aplicativo pode abrir um arquivo.

### 4.59 Associação de arquivo

O Windows associa formatos a aplicativos.

Exemplo:

`.pdf` pode ser associado a um leitor de PDF.

Alterar aplicativo padrão:

- muda o programa usado para abrir;
- não necessariamente converte o arquivo.

### 4.60 Propriedades de disco/unidade

Em noção básica, propriedades podem mostrar:

- capacidade;
- espaço usado;
- espaço livre;
- sistema de arquivos.

Isso pode aparecer em questão objetiva.

### 4.61 Segurança básica do usuário

Em ambiente administrativo:

- bloqueie a sessão ao se afastar;
- não compartilhe senha;
- mantenha atualizações;
- desconfie de executáveis desconhecidos;
- confira extensões quando necessário.

Este lote não substitui conteúdo específico de segurança da informação, se houver.

### 4.62 Como lidar com questão de versão

Exemplo:

> No Windows 11 25H2, onde fica determinada opção?

Você deve:

1. identificar a versão;
2. usar o caminho correspondente;
3. não responder pelo Windows XP.

Outro exemplo:

> No Windows XP, qual ferramenta centraliza configurações tradicionais?

A resposta provavelmente envolverá:

> Painel de Controle.

### 4.63 Regra de ouro

> **Conceito estável primeiro; caminho de menu somente com atenção à versão.**

Essa é a estratégia mais segura para “Windows XP ou mais recente”.

## 6. Exemplos resolvidos ou situações práticas

### Situação 1 — copiar modelo

Existe:

`C:\Modelos\Oficio.docx`

Você precisa criar cópia em:

`C:\Documentos\Agosto`

A operação correta é:

- copiar;
- colar.

O original permanece em Modelos.

### Situação 2 — mover relatório

O arquivo foi salvo na pasta errada.

Mover significa:

- retirar da localização atual;
- colocá-lo na pasta correta.

### Situação 3 — atalho

Você apaga um atalho do Word na Área de Trabalho.

Em regra:

- o programa não foi desinstalado;
- apenas o atalho foi removido.

### Situação 4 — Lixeira

Você exclui arquivo local com Delete.

Em situação comum:

- ele pode ir para a Lixeira;
- pode ser restaurado.

### Situação 5 — exclusão permanente

Você usa `Shift+Delete`.

O Windows solicita confirmação de exclusão sem Lixeira.

### Situação 6 — tela pequena

Texto e aplicativos parecem pequenos.

A questão pede aumentar o tamanho visual sem alterar o conteúdo dos arquivos.

O conceito relevante é:

> **Escala**.

### Situação 7 — monitor sem nitidez

A resolução foi alterada para valor incompatível com o recomendado.

A imagem pode:

- perder nitidez;
- ficar esticada;
- apresentar bordas.

### Situação 8 — versão da questão

A questão informa Windows 11 25H2 e pergunta energia.

Não use um caminho decorado do Windows XP.

Considere o caminho da versão indicada.
